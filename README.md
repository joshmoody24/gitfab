## Installation

1. Install the Stylus browser extension ([Chrome](https://chromewebstore.google.com/detail/stylus/clngdbkpkpeebahjckkjfobafhncgmne), [Firefox](https://addons.mozilla.org/en-US/firefox/addon/styl-us/))
2. Paste the [styles](gitlab.css) into the extension

## Features

- Less contrast
- CI loading spinner
- Merge button glam
